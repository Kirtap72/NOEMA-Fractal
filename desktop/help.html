NOEMA Fractal 1.0

The app works without a development server. WebGPU uses the graphics card of the computer.

Save and open

File → Save scene as saves all scene settings, animation and embedded resources in a portable JSON file. File → Recent scenes opens earlier files. Save picture preset puts an entry of its own in My fractals.

Move the library from the browser

Export the library in the old app. Choose Import library here and open the .library.json or .library.json.gz file. The same ID and content become a duplicate; conflicts cancel the import. The browser data and the backup file are never changed.

Library and backup

File → Show library folder shows the persistent data of the app in Profile\Library (beside the portable launcher). Export library for a portable backup. Internal objects are split losslessly and the index is updated atomically. Do not change internal files by hand. Keep your own backups on a separate disk.

Graphics and recovery

Help → About / graphics status shows the adapter and the storage folder. On device loss: save the scene, quit and open the app again. Saved libraries are restored from disk. The Blender bridge is still a separate, optional tool.
