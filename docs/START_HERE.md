# NOEMA Fractal 1.0 — start here

1. Extract the entire ZIP to a writable folder.
2. Double-click **Start-NOEMA-Fractal.cmd**. Keep the program files together.
3. Choose **Start with a ready-made fractal**, or open your own scene with **File → Open scene**.
4. Explore Shape, Material, Light and Camera. Use Undo to reverse changes.
5. Use the Render tab to render and export a picture. Open **Help → User manual (offline)** for details.

Your library, materials and settings are stored in a new `Profile` folder beside the launcher. No existing profile is copied. Back up that folder to preserve your work. Start using the launcher to keep this portable profile location.

Windows x64 and a WebGPU-capable graphics driver are required. Testing has been performed on an NVIDIA RTX 2080; other hardware is unverified. The executable is unsigned. The first shader compilation can take time.

The download contains no artwork gallery, saved example scenes, presets, private resources or API credentials. The built-in mathematical formula catalog, generic material/light options and initial Mandelbulb remain available. The two presentation artworks are shown only on the project pages.

Rendering is local. AI assistance and online materials are optional. Enter your own API credentials only if you choose to use a provider. Consult KNOWN-PROBLEMS.md before relying on advanced import or export features.
